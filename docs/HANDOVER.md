## 1. 인수인계 핵심 원칙

담당 교역자나 행정 간사가 바뀌더라도 이전 작업자의 개인 `AI` 채팅 기록 없이 즉시 운영과 유지보수를 이어갈 수 있도록 홈페이지를 설계했습니다.

1. **코딩 없는 일상 운영**: 주보 게시, 설교 유튜브 연동, 새가족 문의 확인, 학사관 모집 안내, 헌금 계좌 변경, 교역자 사진 교체, 상단 메뉴 편집은 모두 `/admin` 통합 관리자 화면에서 마우스 클릭만으로 처리합니다.
2. **관리자 전용 원형 챗봇 운영 도우미**: 일반 성도 화면에서는 방문자 안내 챗봇이 표시되고 `/admin` 관리자 모드에 로그인하면 우측 하단에 **관리자 전용 원형 챗봇 버튼**이 나타납니다. 외부 유료 `API` 연결 없이 궁금한 기능을 질문해 즉시 안내받으며 버튼 하나로 해당 메뉴를 열거나 절기 공지 초안과 계정 인수인계표를 확인할 수 있습니다.
3. **코드 수정 인수인계**: 홈페이지 디자인이나 기능 자체를 고치고 싶을 때는 `Cursor`, `Antigravity`, `Claude Code` 같은 `AI` 코딩 도구에서 프로젝트 폴더를 열기만 하면 루트 경로의 `AGENTS.md`와 `docs/BUILD-PROCESS-AND-AI-GUIDE.md`를 읽고 전체 구조를 파악합니다.

## 2. 매주 운영하는 5분 정기 업무 순서

1. **주보 안내 등록** (`/admin?tab=bulletin`)
   - 매주 작성한 주보 한글 파일 (`.hwp`, `.hwpx`)을 업로드하면 예배 순서, 설교 제목, 성경 본문, 교회 소식, 교회 일정, 축하합니다 명단이 자동 추출됩니다. 여러 호의 주보 파일도 일괄 등록 버튼으로 한 번에 선택해 올릴 수 있습니다.
   - 분리된 **교회 소식** 상자와 **교회 일정** 상자를 확인하고 저장하면 성도들이 별도 한글 뷰어 앱 없이 스마트폰과 PC 화면에서 바로 주보를 열람합니다.
2. **설교 영상 등록** (`/admin?tab=sermons`)
   - 상단의 유튜브 채널 동기화 버튼을 누르면 교회 유튜브 채널에 새로 올라온 설교 영상을 자동으로 찾아 예배 구분 (`주일오전예배`, `주일오후예배`, `수요기도회`, `금요기도회`, `새벽기도회`, `특별집회`)과 성경 본문까지 한 번에 등록합니다. 개별 영상 주소를 붙여넣어 단건으로 불러올 수도 있습니다.
3. **새가족 및 온라인 문의 확인** (`/admin?tab=inquiries`)
   - 성도나 방문자가 문의하기 화면 (`/contact`)에서 남긴 새가족 등록, 심방 요청, 행정 문의를 확인하고 처리 메모와 `연락완료` 상태를 기록합니다.

## 4. 사이트 관련 계정 및 서비스별 로그인 구조

홈페이지 도메인, 코드 저장소, 데이터베이스, 웹 서버는 개인 계정이 아닌 **교회 공식 공용 계정**에 귀속시켜 운영합니다. 실제 교회 내부 계정 주소와 만료일 상세 기록은 저장소에 올라가지 않는 로컬 전용 `docs/HANDOVER.private.md` 또는 교회 행정실 보안 문서에 별도로 보관하십시오.

| 서비스 구분 | 담당 역할 | 권장 로그인 방식 | 관리 항목 |
|---|---|---|---|
| **도메인 등록기관** | 공식 도메인 소유권 및 연장 관리 | **교회 공식 구글 계정** | 도메인 자동 연장 및 네임서버 설정 |
| **`GitHub`** | 홈페이지 소스 코드 저장소 보관 | **교회 공식 구글 계정** | 소스 코드 이력 관리 |
| **`Supabase`** | 실시간 데이터베이스 및 첨부파일 저장소 | **교회 `GitHub` 계정** (`Continue with GitHub`) | `app_kv_store` 테이블 및 `church-uploads` 버킷 (무료 한도: DB `500 MB`, 파일 `1 GB`) |
| **`Vercel`** | 홈페이지 웹 서버 배포 및 도메인 연결 | **교회 공식 구글 계정** | `ADMIN_PASSWORD`, `PHOTO_ADMIN_PASSWORD` 및 `Supabase` 환경변수 관리 |

### 2종 관리자 계정 권한 분리 (`/login`)

| 계정 구분 | 로그인 선택 탭 | 환경변수 이름 | 허용 범위 |
|---|---|---|---|
| **사이트 전체 관리자** | 사이트 관리자 모드 (`admin`) | `ADMIN_PASSWORD` | `/admin` 전체 21개 행정 메뉴, 새가족 문의함, 계좌, 사진 업로드 전체 |
| **사진 업로드 전용 계정** | 사진 업로드 전용 (`photo`) | `PHOTO_ADMIN_PASSWORD` | `/admin/photos` 앨범 사진 및 동영상 업로드와 앨범 관리만 허용 |

### 후임 담당자 필수 유의사항

1. **`Supabase` 소셜 로그인 구분**: `Supabase` 프로젝트를 `GitHub` 연동으로 생성한 경우 구글 로그인을 누르면 데이터가 없는 빈 계정이 열립니다. 먼저 브라우저에서 교회 `GitHub` 계정에 로그인한 뒤 `Supabase`에서 **`Continue with GitHub`**를 선택하십시오.
2. **상단 실시간 저장 용량 확인**: `/admin`과 `/admin/photos` 최상단 표시줄에서 데이터베이스 (`500 MB` 무료 한도)와 사진 및 파일 (`1.0 GB` 무료 한도) 현재 사용량을 항상 확인할 수 있습니다. `70%` 이상이면 주황색, `90%` 이상이면 빨간색으로 표시됩니다.
3. **2종 관리자 비밀번호 변경**: `Vercel` 프로젝트 설정의 `Environment Variables`에서 `ADMIN_PASSWORD`와 `PHOTO_ADMIN_PASSWORD`를 수정한 뒤 재배포 (`Redeploy`)하면 기존 로그인 세션이 즉시 만료되고 새 비밀번호가 적용됩니다.
4. **정기 백업 보관**: 분기별 또는 주요 개편 전후에 `/admin?tab=backup`에서 백업 `.json` 파일을 내려받아 교회 행정 컴퓨터나 공용 클라우드에 함께 보관해 두십시오.
